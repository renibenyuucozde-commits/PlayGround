# PlayGround

## LIBERTY BLOCKS — Top-Down Roleplay Live-Simulator

Ein GTA-3-artiges Open-World-Spiel im Blick von oben, komplett in **`index.html` + `game.js`** (kein Build, keine Libraries). Einfach `index.html` im Browser öffnen.

### Features
- Dynamische Stadt (78 Blöcke): Gebäude, Parks, Parkplätze, Trustees, Kreuzungen, Zebrastreifen
- Live-Verkehr mit Rechtsverkehr-AI (Abbiegen, Ausweichen, Panik bei Schüssen)
- Passanten mit Fluchtverhalten und RP-Chat-Einblendungen im Feed
- Fahndungssystem (Sterne 1–6, Polizisten zu Fuß + Streifenwagen, Festnahme/„Busted")
- Autos klauen, fahren, driften (Leertaste), Crashs, Autos explodieren bei starken Beschädigungen
- Jobs: **Taxi-Duty** (T im Taxi), **Courier** (Depot), **Banküberfall** (E an der Bank)
- Shops: Ammu-Nation (Bat/Pistole/MP/Weste), Cluckin' Bell (Heilung), **Pay'n'Spray** ($200 löscht Fahndung)
- Tag-Nacht-Zyklus mit Laternen, Scheinwerfern und Kegellicht
- Waffen: Faust, Bat, Pistole, MP — Maus-Zielsystem
- Sound-Engine (WebAudio): Motor, Sirene, Schüsse, Bargeld-Blips — **M** = mute

### Steuerung
| Taste | Aktion |
|---|---|
| WASD / Pfeile | Laufen / Fahren |
| Maus + Klick | Zielen & schießen |
| F | Auto ein-/aussteigen |
| 1–4 | Waffenwahl |
| Shift | Sprinten |
| Leertaste | Handbremse (Drift) |
| T | Taxi-Duty an/aus |
| E | Interagieren (Bank, Depot, Shops) |
| H / M | Hilfe / Ton |

Debug-Hooks: `?auto=1` überspringt das Intro, `?test=1` = Auto-Fahrmodus, `?tick=1` = RAF-Ersatz für Headless-Tests.
